# dark_glassmorphic_bottom_bar example

Demonstrates how to integrate and use the `dark_glassmorphic_bottom_bar` package with an interactive UI.

## Running the Example

1. Open a terminal in the `example` directory:
   ```bash
   cd example
   ```
2. Get dependencies:
   ```bash
   flutter pub get
   ```
3. Run the app on your preferred simulator, emulator, or connected device:
   ```bash
   flutter run
   ```
